## What this is

Personal portfolio/blog site for Khajan Pandey (iamkhajan), deployed to GitHub Pages at `https://iamkhajan.github.io`. Built with Docusaurus 3.4 + TypeScript + React 18.

## Commands

```bash
yarn start          # local dev server (localhost:3000)
yarn build          # production build to ./build/
yarn typecheck      # TypeScript type-check (no tests exist)
yarn clear          # clear Docusaurus cache
yarn serve          # serve the production build locally
```

**Deploying:** `deploy.sh` amends the last commit and force-pushes to `main`, then runs `yarn deploy` (which builds and pushes to the `gh-pages` branch via `GIT_USER=iamkhajan`).

## Architecture

The site uses Docusaurus's **docs-as-blog** pattern: the `docs/` folder holds content that renders as "Blogs" in the navbar (not the `/blog` route, which is commented out). The sidebar auto-generates from the `docs/` directory structure (`sidebars.ts` uses `autogenerated`).

Content structure:
- `docs/` — primary content (intro/about page + article pages). New articles go here as `.md` files.
- `blog/` — standard Docusaurus blog (currently unused/example content from scaffold).
- `src/pages/index.tsx` — homepage with hero section + `HomepageFeatures` component.
- `src/components/HomepageFeatures/index.tsx` — three feature cards (Digital Transformation, AI/ML, Cloud).
- `static/img/` — images served at `/img/`. Blog post images go in `static/img/blog_images/`.
- `docusaurus.config.ts` — site metadata, navbar, footer, theme config.

## Key conventions

- The navbar "Blogs" item links to `/docs/intro` (the sidebar), not `/blog`.
- "Contact Us" in the navbar also links to `/docs/intro`.
- Images in docs use relative paths from the doc file to `static/`, e.g. `../static/img/blog_images/foo.png`.
- `onBrokenLinks: 'throw'` — broken doc links will fail the build.
- No testing framework is set up; `yarn typecheck` is the only automated check.
